! ============================================================================
! npcsys - NPC life system. Replaces walker / sim_life / wal_main / *_walk.
!
! How it works
!  - npcsys_tick runs when game time has moved on (walker and walk_programm
!    call it). Calls with no elapsed time cost almost nothing.
!  - Every NPC has a wake time (nsw_wake). It thinks about where to be only
!    when that time comes (the next full hour) and then walks there. An NPC
!    that has arrived costs one line per tick until the next hour.
!  - Timetables are data (npcsys_sched_*), not code. One program = a list of
!    rules, first match wins:
!      gs'npcsys_rule', days, from_hour, to_hour, 'options', 'think', 'condition'
!    days: 'all' / 'wd' (Mon-Fri) / 'we' (Sat-Sun); hours may wrap (22..6).
!    options: 'бар|бар2|храм' - one is chosen per day per rule.
!      'place?condition' - option only available while the condition holds.
!      'дом' home, 'прогулка' wander, 'стоп' stay, 'работа' job from work[w],
!      '@expr' follow NPC number expr (e.g. '@grief', '@slave[w]').
!  - Places: npcsys_places. Jobs: npcsys_jobs.
!  - Story side effects live in hooks (npcsys_h_*), run after the timetable.
!  - Interactions (old radarNew) only pair NPCs standing in the same room.
!
! This location builds the tables. 'const' calls it at start-up and on every
! load, so timetable edits apply to existing saves.
! Other code may set nsw_wake[npc]=0 to make an NPC re-plan on the next tick.
! ============================================================================

ns_nr=0

! instead of silently joining the last program of the previous file

	ns_vp=ns_plist[ns_vi]
	if nsp_rn[ns_vp]=0:gs'npcsys_err','программа <<ns_vp>> (<<$nsp_nm[ns_vp]>>) без правил'
end
