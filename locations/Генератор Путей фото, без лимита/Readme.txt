Автоматическая генерация и обновление количества изображений без пересборки всего прооекта

1) Поместить скрипт и папку с генератором в папку с игрой
2) Исправить пути внутри файла generate_configs.py согласно вашему каталогу
3) Запустить командную строку из корня папки игры 
4) Выполнить python generate_configs.py

Automatic generation and updating of the number of images without rebuilding the entire project.

1) Place the script and the folder with the generator in the game folder.
2) Correct the paths inside the file generate_configs.py according to your directory.
3) Run the command line from the root of the game folder.
4) Execute python generate_configs.py.
